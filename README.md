Python Fundamentals Learning Journey

A beginner-friendly collection of Jupyter notebooks for learning the core building
blocks of Python programming. The examples are short, interactive, and designed
to be read and executed one cell at a time.

## What is covered?

The notebooks introduce:

- Python's `main` function convention
- Variables, comments, and the `print()` statement
- Data types, user input, strings, and string concatenation
- Escape characters
- Type casting and type conversion
- Operators and operator precedence
- Lists
- The `random` module
- Conditional statements with `if`, `elif`, and `else`
- `for` loops and `while` loops

## Recommended learning order

1. Work through the numbered notebooks in `My first python assingment`, starting
   with `00_Python_Main_Function.ipynb`.
2. Continue with `if_else.ipynb` to learn decision-making.
3. Practice repetition with `for_loops.ipynb`.
4. Finish with `while_loops.ipynb`.

Try changing the examples and predicting the output before running each cell.
This is a study repository, so experimenting with the code is encouraged.

## Requirements

- Python 3.8 or newer
- Jupyter Notebook or JupyterLab

No third-party Python packages are required for the examples in this repository.

## Getting started

Clone the repository and move into the project folder:

```bash
git clone https://github.com/sharmanageshwor/My-first-python-assignment.git
cd My-first-python-assignment
```

Optionally create a virtual environment:

```bash
python -m venv .venv
```

Activate it on Windows:

```powershell
.venv\Scripts\Activate.ps1
```

Activate it on macOS or Linux:

```bash
source .venv/bin/activate
```

Install Jupyter and launch the notebooks:

```bash
python -m pip install jupyter
jupyter notebook
```

Then open a notebook in the browser and run its cells from top to bottom.

### Google Colab

The notebooks are also compatible with Google Colab. Upload a notebook to
[Google Colab](https://colab.research.google.com/) or open it from a hosted
repository, then run each cell interactively.

## Learning goals

By the end of this collection, you should be able to write small Python
programs that accept input, work with common data types, make decisions, repeat
operations, and use simple standard-library functionality.
